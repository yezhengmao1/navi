# 引用其他会话

此功能由 magic-ui/index.ts 统一注册，不是独立扩展，也不替换编辑器。

- 单个 `@`：保留 Pi 原生本地文件和目录补全。
- 在输入框行首或空白后键入 `$`：像原生 `@` 一样在输入框下方显示会话补全，继续输入关键词可筛选，↑↓ 选择、Enter/Tab 插入引用。Esc 关闭候选并保留普通字符，提交时不会重新打开选择器。异步加载候选，不占用编辑器焦点。
- `/mention [关键词]`：按标题、首条消息、目录或 ID 筛选会话，选择后在编辑框追加 `$session:完整ID`，不会立即发送。
- 普通 `$`、`$关键词` 和旧的 `@@` 提交时均作为普通文字，不触发会话选择。
- `参考 $session:ID 帮我继续分析`：直接引用，支持唯一 ID 前缀。旧的 `@session:ID` 不再识别为会话引用。同一条消息最多三个不同 ID 引用。
- `@src/file.ts` 等文件引用及本地目录补全不受影响，无须先取消会话弹窗。

检索默认会话存储和当前会话目录，排除当前会话。不切换或修改源会话。发送时只附加会话 ID 和 JSONL 文件路径，**不注入历史正文、标题、首条消息或摘要**。模型收到提示后按任务需要检索、分段读取，像引用本地文件一样。

路径指向原始 JSONL，不是快照；内容可能继续变化，也可能包含其他分支、工具记录和敏感信息。模型读取时应区分分支，避免无关凭证。按需读取的内容仍会发送给当前模型提供商。取消或失败时恢复输入文字；附件如有需要须重新添加。旧版已注入当前会话的正文不会因更新自动移除。

## 查看已注册来源与排查不可见会话

在交互式终端执行 `/session list`，立即重新执行一次有界只读扫描，并清除候选缓存。使用普通选择列表列出注册来源：↑↓ 移动、Enter 直接查看当前来源详情、Esc 取消且不查看详情。无复选框、搜索框或「查看详情/取消」按钮，不需要空格选择和提交。支持滚动查看全部 64 个来源；窄窗口会截断选项，选中后查看完整详情。列表不执行移除操作。RPC 模式回退到文本通知；无 UI 模式拒绝执行。空列表或配置读取失败直接显示提示。

详情显示来源 ID（用于 `/session remove`，不是会话 ID）、类型、别名、完整目录和状态，以及：

- **目录内已索引**：本次扫描结果中落在该目录下的去重会话数，包含已由父来源扫描的会话。
- **归属本来源**：首次通过此来源识别的会话数；父子目录重叠时，子来源可能为 0，但不代表没有会话。
- **本次扫描 JSONL / 目录项 / 读取字节**：实际扫描工作量，不是文件系统总量；所有来源共享下述预算。
- **无有效元数据 / 读取错误 / 跳过链接**：用于区分非 Codex JSONL、无效/超长元数据、权限问题和链接跳过。

状态 `ok` 表示扫描完成（可能为空）；`partial` 表示部分文件没有有效元数据；`overlap` 表示目录已由另一来源扫描。`ENOENT` / `EACCES` / `ENOTDIR` 等表示路径或读取问题；`symlink-skipped` 表示来源被替换为链接。`limit` / `prefix-limit` / `depth-limit` 表示结果可能不完整。配置损坏会明确报告警告，不会误称尚未注册。

列表只显示来源元数据和汇总计数，不显示会话标题、ID、工作目录或正文，不修改注册表和外部会话文件。仅列出显式注册的外部来源；Pi 原生会话仍自动检索。

看不到会话时先执行 `/session list`，然后用 `$yxing02` 或 `/mention yxing02` 筛选（裸 `$` 只显示最新的前 30 个匹配结果）。若命令不可用，检查实际加载的 magic-ui 是否已更新：仓库源码目录不等于全局复制安装目录，复制部署后须 `/reload` 或重启。

## 移除来源注册

```text
/session remove
/session remove codex-<完整目录哈希>
```

无参数时在 questionnaire 单选卡片选择注册来源并提交「下一步」，随后在独立确认卡片用空格勾选「是」并提交「确认移除注册」。确认默认否；Esc、取消或未勾选确认均不做任何修改。提供完整来源 ID 可跳过选择，但仍必须确认；不接受 ID 前缀、别名、目录路径或会话 ID，避免歧义。

仅删除 `<agent-dir>/magic-ui/session-sources/` 下对应注册 JSON，**绝不删除原始目录或会话文件**。原目录已丢失或不可访问也可以取消注册。成功后立即清除会话候选缓存；其他重叠来源仍可能索引同一会话。仅交互式终端可移除，RPC/无 UI 模式不能绕过确认。配置损坏时报告错误而不是猜测要删除的文件。

## 注册外部 Codex 会话

```text
/session add codex /path/to/codex/sessions
/session add codex "/path/with spaces/sessions" --name "Display Name"
/session add codex /volume/pt-dev/users/yxing02/.codex/sessions/ --name yxing02
```

路径直接来自命令参数，不弹出路径输入框。支持单/双引号、相对当前工作目录的路径和 `~/`；不执行 shell、不展开环境变量。目录必须存在且可遍历。路径和名称含空格时须用单/双引号包裹；不处理 shell 转义。未知参数、重复 `--name`、缺少值或多余路径会报错。名称须为 1–128 个字符，不得为空白或包含控制字符。重复注册（包括符号链接别名）不会重复保存；显式指定 `--name` 会更新该规范目录的显示别名，不指定则保留原别名。语法预留 `/session add <pi|codex|claude> <path>`，目前仅实现 `codex`，其他类型会明确报错。裸 `/session` 仍是 Pi 原有统计及 editor-footer 上游信息，不受影响。

来源保存在 `<agent-dir>/magic-ui/session-sources/codex-<目录哈希>.json`（默认 agent-dir 为 `~/.pi/agent`），重启后仍有效。注册成功立即清除候选缓存；外部新增文件和其他进程注册的来源在候选缓存过期（10 秒）后重新扫描。使用 `/session remove` 可取消注册；不会删除外部文件。

`$` 的外部候选有别名时左侧显示 **[Codex · yxing02]**，标题直接显示原始 session ID（不加 `Codex` 前缀，也不使用元数据名称），右侧仅显示工作目录路径，不重复来源信息或会话 UUID；原生会话右侧同样仅显示工作目录。完整会话 ID 仍保留在插入值中。`/mention` 保留详细来源信息。两者仍可按 **Codex/external** 标记、来源目录和来源 ID 搜索。同一原始 Codex ID 在不同文件/目录中不会合并：引用 ID 由文件路径生成，与 Pi ID 碰撞时再加 `external-` 前缀。重叠来源按规范路径去重，归属首次遍历到的来源。别名仅用于显示与搜索，不改变来源 ID 或会话引用 ID。引用附加别名（如有）、原始 Codex ID、来源标识与文件路径，但不注入正文，也不将 Codex 当作 Pi 分支树解析。

扫描只读，递归读取 `.jsonl` 中的 `session_meta.payload` 元数据，不导入、续接或修改外部会话。不跟随扫描中的符号链接，不读取特殊文件；损坏记录、不可访问文件会跳过。每次最多遍历 20,000 个目录项、2,000 个 JSONL 文件、16 层子目录，单文件前缀最多 256 KiB、总读取最多 32 MiB，最多注册 64 个来源。只解析完整记录；超出前缀的元数据不会出现于候选。达到限制或来源不可读时显示警告，可注册更小的目录。

安装或更新 magic-ui 后 `/reload` 生效。

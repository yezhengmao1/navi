# SwanLab 指标说明

> 复制到 `~/.navi/swanlab-metrics.md` 后按你的实验改。你只写「单个指标是什么」，
> **指标间的关系由 workflow 自动从数据挖掘**，不用写。
>
> 格式：每个指标一个 `### 指标名`（与 SwanLab key 完全一致），下面任选字段填：
> **含义** / **期望趋势** / **健康范围** / **异常信号**。成百上千条的 `前缀/*` 指标用「指标族」整体描述。

### lm loss
- **含义**：语言建模交叉熵损失，最核心的健康度量。
- **期望趋势**：单调下降，前快后缓。
- **异常信号**：NaN/Inf；尖峰不回落；长期平台。

### grad-norm
- **含义**：全局梯度范数（裁剪前）。
- **期望趋势**：缓降趋稳。
- **异常信号**：尖峰常领先 loss spike；持续走高=不稳定；骤降到 0=梯度消失。

### load_balancing_loss
- **含义**：MoE 路由负载均衡辅助损失。
- **异常信号**：持续偏高/上升=路由塌缩、专家利用不均。

## 指标族（前缀型，整体描述）

### grad-norm/*
每参数/专家梯度范数。看点：族内是否有离群层/专家（范数异常大或为 0）。

## 关系提示（可选）

> 留空即可。只在确信某耦合时点一句当先验，例：grad-norm 尖峰通常领先 lm loss spike 1–2 步。

为什么 loss 看不见：final_layernorm 全吸收

末层残差在 FP8 里涨到 2–3×，但送进 unembedding 前的 final_layernorm_out 四个 run 全程钉在 ~1.28——放飞被 loss 前唯一的归一化点完全吃掉。这是 loss/评测无感的机械原因，与 per-层 norm 摆放无关。

机制拆解

放飞 = 结构许可 × 驱动力 × 位置

结构许可：MoE 分支无 post-norm，expert 输出直进残差，幅度不受约束（注意力/稠密首层有 post-norm，就压得住）。

驱动力：E5M2 只有 2 位尾数（误差 ~25% vs E4M3 的 ~12%），反向梯度粗量化推着末层 expert 权重单调长大；去 power-of-2 多一次舍入 → WOPOWER2 最凶。

位置：末层输出只喂 final_LN、无下游，自由度拉满 → 漂移集中在 L18。

无 post-norm  ×  E5M2 粗梯度  ×  末端位置  →  离群正反馈

E5M2 反向：per-tensor 的遗产，blockwise 下反转

「E4M3 前向 + E5M2 反向」出自 2022 per-tensor 方案：梯度动态范围宽，需 E5M2 的 5 位指数防溢出。

但这里是 128-blockwise：动态范围已由 per-block scale 解决，E5M2 的指数冗余、2 位尾数成净损失。DeepSeek-V3 在细粒度 FP8 下前后向全用 E4M3——数据符合的是这个现代结论。

blockwise scale 罩住范围  →  E5M2 指数无用  →  只剩尾数劣势  →  用 E4M3

结论与建议

实测质量四者打平（loss ±0.004、评测 ±0.4）。但 E5M2 两个配方末层激活仍单调上升；一旦某 block 峰值顶到 E4M3 前向上限（~448），block-max scale 被它主导、同 block 其余元素量化到近零 → 触发真正发散。两条修复正交，可叠加：

  1. 架构（治本）：给 MoE 分支加 post_mlp_layernorm FIX 与稠密首层、注意力分支对齐。同模型已证明：相同 FP8 放大下，有 post-norm 就压得住。对 BF16 也只有稳定收益。
  2. 格式：blockwise 用 FB-E4M3（全 E4M3） SAFE DeepSeek-V3 正解；E5M2-bwd 是 per-tensor 遗产，此处只带来更糙的梯度。
  3. 不建议 WOPOWER2 RISK E5M2 + 去 2 幂，离群最重（+355%），潜伏的发散定时炸弹。

下一个 ablation：F/B-E5M2 只给 MoE 加 post_mlp_layernorm，看末层 ffn_out 是否从 2.3 收回 ~0.5——一次同时验证放飞机制与修复手段。
